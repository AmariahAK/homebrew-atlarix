# Homebrew tap for the Atlarix CLI

**[Atlarix CLI](https://atlarix.dev/cli)** is an AI coding agent in your terminal. It plans,
builds, reviews and tests code with you, works with any model (Atlarix Auto, your own API key,
or a local model through Ollama or LM Studio), and shares the
[Atlarix desktop app](https://atlarix.dev)'s sessions, keys and settings.

## Install

```bash
brew install amariahak/atlarix/atlarix
atlarix --version
```

Then run `atlarix` in any project folder.

## Upgrade and uninstall

```bash
brew upgrade atlarix
brew uninstall atlarix
```

The formula is updated automatically on every release.

## Other ways to install

```bash
curl -fsSL https://atlarix.dev/install | sh          # macOS, Linux
irm https://atlarix.dev/install.ps1 | iex             # Windows (PowerShell)
npm install -g atlarix                                # npm
```
